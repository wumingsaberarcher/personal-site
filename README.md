# Tiancheng Li · Personal Signal Station

Single-page Outer Wilds–leaning site for NZ recruiters.

## Sections

- `#signal` — Hero
- `#relics` — LearnChain · Nexus · Exterminatus
- `#operator` — About / dossier
- `#uplink` — Contact + resume

EN / 中文 toggle in the top bar (persists in localStorage). Resume PDF switches with locale.

Canal / DeepSeek UI = phase 2 (not in v1).

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist/` folder (Vercel / static host).
